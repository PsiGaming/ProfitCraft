## Versions

## How we work
- **Publishing:** only when the author asks to commit; then every commit of addon code is also published (new `.toc` version, tag, zip, GitHub pre-release), because the author can only test through WowUp, which only sees releases (2026-11-17). Run the opsec scanner before every commit (also installed as the repo's pre-commit hook): no personal names, character, realm or account names, or details of the author's system in the repo. "Build" alone = build and test, no commit or release. Commits touching only `plan/` need no release.
- **Zip:** `git archive --prefix=ProfitCraft/` (the `plan/` folder, `.gitattributes` and `.editorconfig` are excluded via `.gitattributes`).
- Evidence for Forever API facts: Blizzard's Forever UI source (Gethe/wow-ui-source, branch `forever`; shallow clone ~54 MB into /tmp) and PsiLab results; reference addons are idea sources, not proof.
- Tests: LuaJIT via `lupa` in a temp venv (`uv venv /tmp/luachk && uv pip install --python /tmp/luachk/bin/python lupa`) with stubbed WoW functions. The harness lives in `/tmp/pcraft-test/` (`harness.lua`, `run.py`; older versions kept as `harness.<version>.lua`) and is gone after a reboot; recreate it rather than skipping tests (it simulates login, opening a profession, prices from a fake Auctionator, AH scans and searches, all windows and settings). Its `string.format` errors on nil like WoW's Lua 5.1.
- The author reviews uncommitted changes in Claude Code's `/diff` (open Claude Code in the addon's folder). New files: `git add -N`.
- File changes with the Edit tool (Read, then Edit/Write), not Python or sed replacement scripts (2026-11-21).
- The author doesn't read Lua; explain changes in plain words, keep answers short and concrete.
